Reading the comparison

Both series use micrograms per cubic metre (µg/m³). Each model value at the labelled hour is compared with the monitor’s hourly reading at that UTC timestamp. A grid estimate represents a wider area around the station. Gaps are excluded from paired statistics. The concentration alone cannot identify the pollution source.

CAMS Global provides three-hourly fields on a roughly 45 km grid. Open-Meteo supplies hourly interpolated values. The model and monitor peaks below each chart use only hours with both values, and ties use the earliest hour.
